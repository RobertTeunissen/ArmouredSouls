Spec 55 — Automaton Stables: player page mockups

Static mockups for review. Colours and spacing use the theme tokens from app/frontend/src/index.css. The only new element is the Automaton badge; everything else is the page as it is today.

Each page is shown at mobile width (360 px) and desktop width. Sample data comes from the starter catalogue (review/CATALOGUE.md).

The badge

Label "Automaton", gear icon, theme info purple. No tooltip. It always sits on the same line, directly after the stable name, like "YOU". In rows, tables and battle banners narrower than 640 px it shows only the gear, so stable names stay readable at 360 px; page headers (stable profile, robot owner) keep the full label. Screen readers always hear "Automaton". Two sizes: md next to names, sm in the dense archive tables. Shown next to the existing badges it must not be confused with.
