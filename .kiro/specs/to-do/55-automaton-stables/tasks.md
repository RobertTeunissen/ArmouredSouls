# Implementation Plan: Automaton Stables

## Overview

Spec 55 delivers persistent, strategy-driven Automaton_Stables in test-first increments: classification and access first, then the route-embedded purchase logic moved into services, then the pure engine, then the content-dependent strategies, execution, settlement wiring, rollover, catalogue, admin surfaces, player-facing surfaces, a heavy simulation, documentation and the aggregate verification gate.

Content-dependent work is gated by Content_Approval (Task Group 0). Everything else may start immediately.

All tasks are mandatory. Each task group lists its requirement trace; leaf tasks name the criteria they implement or prove.
